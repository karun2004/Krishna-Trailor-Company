# Krishna Trailor Company

Website and admin CMS for Krishna Trailor Company. Built with Next.js 15 (App Router), TypeScript, Tailwind CSS v4 and Supabase.

## Getting started

```bash
pnpm install
cp .env.example .env.local   # then fill in the Supabase values
pnpm dev
```

## Tests

```bash
pnpm vitest run
```
